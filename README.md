# AWS Cloud Security Foundations

## Project Overview

This project is a practical introduction to Cloud Security Engineering, using Amazon Web Services (AWS) as the primary hands-on learning environment.

The objective is to understand fundamental cloud security principles, identify common security risks, explore AWS security controls, and document practical security exercises.

The project emphasizes security by design, least privilege, defence in depth, secure authentication, network security, and continuous monitoring.

## Objectives

- Understand the AWS Shared Responsibility Model.
- Apply the CIA Triad to cloud environments.
- Explore Identity and Access Management (IAM).
- Understand least-privilege access.
- Examine cloud network security fundamentals.
- Explore logging, monitoring, and threat detection.
- Document security risks and recommended mitigations.

## Security Principles

This project follows these principles:

- Least privilege
- Defence in depth
- Secure authentication
- Encryption and data protection
- Continuous monitoring
- Cost-conscious cloud usage

## Security and Cost Considerations

- AWS root credentials will not be used for routine administration.
- No passwords, access keys, private keys, or sensitive credentials will be committed to this repository.
- AWS resource deployment will be reviewed for cost implications before execution.
- Practical exercises will prioritize read-only operations and local testing where possible.
